# 0.2.0

The default demo now creates and verifies real signed JEP-Core-0.6 J/D/T/V events through the Python SDK and a local API. Historical mock data is available only through explicit `--legacy-mock` replay. The executable is now `jep-e2e`, leaving `jep` to `jep-cli`. Existing archive bytes are preserved in `legacy/archive.jsonl`.

GitHub provides installable distributions. No new PyPI publication or live API deployment is configured by this release.
